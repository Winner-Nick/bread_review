## 已知行为变化

### 与旧版本的区别
1. **不再动态分配题目**：所有题目在初始化时一次性分配好
2. **没有跳过按钮**：只有"记得"和"忘记"两个操作
3. **忘记不再重新分配**：点击忘记只是标记状态，题目仍在当天
4. **今日剩余实时更新**：点击记得后立即减少，无需刷新页面
5. **题目状态可见**：每个题目都显示是"记得"还是"忘记"

### 新增功能
1. **初始化界面**：首次使用或重新初始化时的友好界面
2. **状态标签**：直观显示每个题目的学习状态
3. **实时反馈**：操作后立即更新UI，无需刷新
4. **重置功能**：一键清空所有数据，重新开始（V3.1新增）
5. **双重确认**：防止误操作的安全机制（V3.1新增）

## 常见问题排查

### 问题1：初始化失败
**可能原因**：
- data目录不存在或无写权限
- points_pool.json不存在（需先运行scripts/generate_pool.py）

**解决方案**：
```bash
mkdir data
chmod 777 data
python scripts/generate_pool.py
```

### 问题2：API返回非JSON内容
**可能原因**：
- PHP文件有语法错误
- 使用file://协议而非http://

**解决方案**：
- 检查PHP错误日志
- 确保使用 `http://localhost:8000` 访问

### 问题3：今日剩余数不对
**可能原因**：
- 之前标记的题目状态不一致

**解决方案**：
- 查看 `data/daily_assignments.json` 中的completed数组
- 查看 `data/points_pool.json` 中题目的status字段
- 使用重置功能清空所有数据并重新初始化

### 问题4：无法进入初始化界面
**可能原因**：
- 浏览器缓存了初始化状态
- daily_assignments.json文件存在但内容不完整

**解决方案**：
- 点击"🔄 重置系统"按钮
- 或手动删除 `data/daily_assignments.json` 并清空浏览器缓存
